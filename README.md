### 🔸 VLM-Enhanced Autonomous AI Security Patrol (Graduation Project, Team 3)
A two-level hierarchical AI security pipeline supervised by Dr. Rami Zewail:
- **System 1:** INT8-quantized FOMO MobileNetV2 model running on an Arduino Portenta H7 with HM01B0 Vision Shield for fast, on-device object detection with motion-triggered deep standby power management.
- **System 2:** A Groq-hosted Vision-Language Model (LLaMA-4 Scout) for semantic security reasoning.
- Trained on a custom 494-image dataset across four classes, with live evaluation reaching TRL 4.
